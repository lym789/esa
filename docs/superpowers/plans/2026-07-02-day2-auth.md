# Day 2 登录实施计划

> **给自动化执行者：** 实施本计划时按任务逐项执行，并使用复选框记录进度。

**目标：** 为 Enterprise Support Agent MVP 建立 Day 2 登录与角色基础能力。

**架构：** FastAPI 负责认证、JWT 签发、角色依赖、用户持久化和种子账号。Next.js 保留 JadeFlow Dashboard 作为登录后的应用主界面，并新增登录路由和本地 token 存储。

**技术栈：** FastAPI、SQLAlchemy、python-jose、Pydantic、Next.js 14、React 18、TypeScript、Tailwind CSS。

## 全局约束

- 保留现有 JadeFlow AI Dashboard 视觉方向。
- Day 2 只实现用户、登录、当前用户查询、RBAC 依赖、种子账号和前端登录流程。
- 本阶段不实现文档上传、RAG、工单、审批或执行链路追踪页面。
- 4 个种子账号的密码必须是 `123456`。
